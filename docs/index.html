What it does

File sidebar, multi-tab Markdown editor, live preview, and a terminal — all in one resizable layout.

An AI agent in the loop

A real terminal wired into your workspace, with one-click presets to launch an AI agent and a slash-command guide for structured tasks.

Simple or advanced

A guided view for quick edits, or a full file-tree view for browsing the raw workspace like any other project.

Export-ready

Live Markdown preview with one-click PDF and DOCX export, plus git-backed version history.

Opening the app on macOS

  1. This build is signed but not notarized — that costs an Apple Developer Program membership ($99/yr), which this personal project doesn't have. macOS will still flag it as being from an unidentified developer the first time you open it. Here's how to get past that, once.
  2. Open the downloaded .dmg and drag Résumé Studio into Applications.
  3. Try opening it normally first. If you get a warning dialog, go to System Settings → Privacy & Security, scroll down, and you'll see "Résumé Studio was blocked." Click Open Anyway, then confirm on the next prompt.
  4. From then on it opens normally, like any other app.

This is standard for any app distributed outside the Mac App Store without a paid developer account — it's not specific to this app, and it's a one-time step.

Opening the app on Windows

  1. Same story as macOS: no code-signing certificate ($200-500/yr for one trusted by Windows out of the box), so Windows SmartScreen will flag the installer as unrecognized. Here's how to get past that, once.
  2. Run the downloaded .exe. You'll see a blue "Windows protected your PC" screen.
  3. Click More info, then click the Run anyway button that appears.
  4. The installer runs normally from then on, and so does the app.

Same caveat as macOS — this is a limitation of self-distributing outside an app store without a paid signing certificate, not a bug in the app itself.
